# Wynton Zhang

Personal portfolio for digital hardware, robotics, and embedded systems internships.

## Publish with GitHub Pages

1. Create a **public** repository named exactly `zeinork.github.io` under the `Zeinork` account. If it already exists, update that repository instead.
2. Extract this ZIP. Upload the **contents** of the extracted folder to the repository root, including `index.html`, `assets/`, `code/`, and `.nojekyll`. Do not upload the ZIP itself or place the site in a nested folder.
3. Commit the files to `main`.
4. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
5. Check the Pages deployment and visit https://zeinork.github.io/ once it succeeds. Publication can take up to 10 minutes.

## Custom domain later

Once you own a domain, add it in Settings → Pages → Custom domain and configure its DNS using GitHub's documentation. No redesign is required. This package intentionally has no CNAME until a domain is selected.

## Project source

- `code/digital-hardware/`: selected Verilog RTL, with scope and dependency notes.
- `code/robotics/`: selected Python task-method extensions, with scope and dependency notes.
- `assets/code/`: downloadable source packages and plain-text previews.

These are source samples, not complete runnable course projects. The uploaded multiplier is an early checkpoint; division is not included. Course scaffolds and supplied helpers are excluded. See the individual READMEs.

## Editing

Edit `index.html` for portfolio content and styles. Replace resume PDFs in `assets/` while preserving their filenames. No build step or external JavaScript dependencies are required.
